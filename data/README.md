# Dataset Information

For this project, the dataset will be sourced from **Roboflow Universe** (PKLot / Parking Space dataset).

## Details:
- **Source:** Roboflow Universe (Public Dataset)
- **Labels / Classes:** `vacant`, `occupied`
- **Estimated Size:** ~1,000 to 1,500 annotated images
- **Usage:** The dataset will be downloaded directly inside the Google Colab training notebook using the Roboflow API export.
